# Русские шашки «Star Wars» — hot-seat на HTML/CSS/JS

## Context
Пользователь хочет браузерную игру «Русские шашки» для двух игроков за одним компьютером, оформленную в стиле «Звёздных войн». Директория `/Users/user/Developer/claude-test` пуста — пишем с нуля, без сборщиков и зависимостей (открывается двойным кликом по `index.html`).

## Файлы
- `index.html` — разметка: заголовок, панель текущего хода, доска 8×8, счётчики сбитых фигур, кнопки «Новая игра» / «Отменить ход», оверлей победы.
- `style.css` — оформление в стиле Star Wars.
- `game.js` — логика правил + отрисовка + обработка кликов.

## Оформление (Star Wars)
- Фон: чёрный космос с мерцающими звёздами (CSS `radial-gradient` + анимация), шрифт Orbitron/Audiowide с Google Fonts, жёлтый «кроулинг»-заголовок.
- Стороны: **Джедаи/Повстанцы** (синие/зелёные световые мечи, белые фишки) против **Ситхов/Империи** (красное свечение, тёмные фишки).
- Фишки: круги с неоновым свечением (`box-shadow`) и эмблемой стороны (inline SVG: символ Альянса повстанцев / Галактической Империи) — без внешних картинок.
- Дамка: золотая корона-свечение + пометка (например «★» / «Мастер» / «Лорд»), пульсирующая анимация.
- Тёмные клетки — металлические панели с тонкой подсветкой; подсветка допустимых ходов «лазерными» точками, обязательных взятий — красным пульсом.
- Анимация перемещения фишки и «взрыв» при взятии (CSS keyframes).
- Адаптивность: доска `min(90vw, 80vh)`, работает на телефоне.

## Правила русских шашек (game.js)
- Доска 8×8, игра на тёмных клетках, по 12 фишек, первыми ходят светлые (Джедаи).
- Простая фишка ходит вперёд по диагонали на 1 клетку; **бьёт вперёд и назад**.
- **Взятие обязательно**; при нескольких вариантах игрок выбирает любой (не обязательно максимальный).
- Серия взятий: после взятия, если можно бить дальше — продолжает той же фишкой (ход не передаётся). Сбитые фишки снимаются после окончания серии, через одну фишку дважды перепрыгивать нельзя (турецкий удар).
- Фишка, дошедшая до последней горизонтали, становится дамкой; если это случилось во время взятия и можно бить дальше — продолжает бить уже как дамка.
- **Дамка («дальнобойная»)**: ходит на любое число клеток по диагонали; бьёт на расстоянии, может встать на любую свободную клетку за сбитой фишкой (с приоритетом клеток, откуда возможно продолжение взятия — по русским правилам обязательно продолжать, если можно).
- Конец игры: у соперника нет фишек или нет ходов → победа.

### Структура кода
- `board[8][8]`: `null | {side:'light'|'dark', king:bool}`.
- `getCaptureMoves(r,c, captured)` / `getSimpleMoves(r,c)` / `getAllMoves(side)` — генерация ходов с учётом обязательного взятия.
- Состояние: `turn`, `selected`, `chainPiece` (фишка в середине серии), `pendingCaptured`, `history` (для Undo — снимки доски).
- `render()` перестраивает DOM доски; клики: выбор фишки → подсветка целей → ход.
- Панель: «Ход: Джедаи / Ситхи», счётчик сбитых, сообщение «Обязательное взятие!».
